- This repository and its conversation are for the research website, https://anthesis.ac.cn.
- The personal website, https://zhuzhenfang.com, is managed in a separate folder and conversation. Do not modify or publish it from this conversation.
- Do not extend research-website work to GitHub profile content, other repositories, or company websites unless the user explicitly changes this scope.

## Review and publishing

- Prepare changes locally and validate them before presenting the actual changes for review.
- Every batch requires the user's explicit confirmation before any push or deployment. A request to edit is not authorization to push. Approval for an earlier batch does not authorize later changes.
- Keep changes local while awaiting confirmation. Once the user explicitly approves the reviewed batch, commit and push only that approved scope, then verify the remote result and any applicable deployment.
- Check for existing uncommitted work before staging and preserve unrelated changes.
- Report clearly what is local, what has been pushed, and what has been verified live.

## File safety

- Follow the user's global recoverable-deletion policy. Never permanently delete files or directories.
- On this Mac, move each explicit absolute path to recoverable Trash using exactly `/usr/bin/trash <absolute-path>`, one target per command.
- Do not use destructive Git cleanup or bulk discard operations.
